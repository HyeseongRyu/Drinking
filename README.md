# 🍻 드링킹 아카이브

맥주 / 막걸리 / 와인 / 위스키 / 소주 등 술 종류별로 사진과 함께 시음 기록을 남기고,
종류에 맞는 항목으로 1~5점 평점을 매겨 총 평점을 계산하는 개인용 술 기록 웹앱입니다.
모바일과 PC 모두에서 쓸 수 있도록 반응형으로 만들었고, 즐겨찾기로 아카이브를 관리할 수 있습니다.

## 구조

```
Drinking/
  server/   Express + SQLite API (사진 업로드, 기록 CRUD, 즐겨찾기)
  client/   React + Vite 프론트엔드 (반응형 UI)
```

- 여러 기기(휴대폰, PC 등)에서 같은 기록을 보려면 `server`를 항상 켜져 있는 서버에 배포해야 합니다.
- 사진 파일은 `server/uploads`에, 기록 데이터는 `server/drinking.db`(SQLite)에 저장됩니다. 둘 다 **디스크에 영구 저장**되어야 하므로, 배포 환경은 재시작 시 파일이 사라지지 않는 곳(영구 디스크/볼륨 지원)을 선택해야 합니다.

## 술 종류별 평가 항목

| 종류 | 항목 |
|---|---|
| 🍺 맥주 | 향, 탄산감, 쓴맛, 목넘김 |
| 🥛 막걸리 | 단맛, 산미, 탄산감, 목넘김 |
| 🍷 와인 | 향, 산미, 바디감, 여운 |
| 🥃 위스키 | 향, 스모키함, 도수감, 피니시 |
| 🍶 소주 | 부드러움, 단맛, 알코올감, 목넘김 |
| 🍹 기타 | 향, 맛, 질감, 여운 |

각 항목은 1~5점으로 평가하고, 총 평점은 항목 평균으로 자동 계산됩니다.
항목을 추가/수정하려면 `server/categories.js`만 고치면 서버·클라이언트에 자동 반영됩니다.

## 로컬 개발

```bash
npm install          # 루트에서 한 번만 (workspaces로 client+server 함께 설치)
npm run dev           # server(:3001) + client(:5173) 동시 실행
```

브라우저에서 http://localhost:5173 접속. (같은 와이파이의 휴대폰에서 테스트하려면 PC의 로컬 IP로 접속: `http://<PC의-IP>:5173`)

## 프로덕션 빌드 & 실행 (단일 프로세스)

```bash
npm run build   # client를 client/dist로 빌드
npm start        # server가 API + 빌드된 client를 함께 서빙 (기본 포트 3001)
```

`PORT` 환경변수로 포트를 바꿀 수 있고, `DB_PATH` 환경변수로 SQLite 파일 위치를 지정할 수 있습니다.

## 배포 (여러 기기 동기화)

이 앱은 Node 프로세스 하나만 계속 떠 있으면 되므로, **영구 디스크(볼륨)를 지원하는** 곳이면 어디든 배포 가능합니다.

- Railway, Render, Fly.io 등의 PaaS + Persistent Volume/Disk
- 저렴한 VPS (예: Oracle Cloud 무료 티어, Cafe24, 개인 서버) + `pm2`나 `systemd`로 상시 실행

⚠️ Vercel/Netlify 같은 서버리스 플랫폼은 파일 시스템이 요청마다 초기화되므로 SQLite + 로컬 사진 업로드 방식과는 맞지 않습니다. 서버리스로 가려면 별도의 관리형 DB(Postgres 등)와 오브젝트 스토리지(S3 등)로 바꿔야 합니다.

배포 후에는 클라이언트가 같은 오리진(`/api`, `/uploads`)으로 요청하므로 별도 설정 없이 바로 여러 기기에서 접속해 같은 기록을 볼 수 있습니다.

## 사용법

1. 오른쪽 위(또는 하단 + 버튼)로 새 기록 추가
2. 사진 선택 (모바일에서는 카메라 바로 실행) → 술 이름 입력 → 종류 선택
3. 종류에 맞는 항목별로 별점(1~5) 선택 → 총 평점 자동 표시
4. 저장하면 아카이브 목록에 카드로 추가됨
5. 카드 우상단 하트로 즐겨찾기 토글, 상단 필터에서 종류별/즐겨찾기만 보기 가능
6. 카드를 눌러 상세 보기 → 수정/삭제 가능
